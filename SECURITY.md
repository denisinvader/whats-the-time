# Security

The skill reads the host clock and prints a local JSON snapshot. It does not make network requests, inspect project files, or store the result. Like any agent skill, its script runs with the permissions granted by the host harness; review changes before installing an untrusted fork.

Please do not put a vulnerability report in a public issue. Use GitHub's **Report a vulnerability** option in this repository's Security tab if it is enabled. If it is unavailable, contact the repository maintainer privately through a channel listed on their GitHub profile. Include the affected version or commit, a minimal reproduction, and the expected impact. We will acknowledge the report and coordinate a fix before public disclosure.
